# figma-bridge marketplace

本仓库包含 [figma-bridge](./figma-bridge) 插件及其本地 marketplace 清单（`marketplace.json`）。

figma-bridge 让 ZCode 这类 AI 编码助手直接读写 Figma：解析 figma.com 链接读取设计稿，由 AI 生成整套 UI 页面并通过本地桥接写回 Figma 文件。功能、安装与安全说明见 [figma-bridge/README.md](./figma-bridge/README.md)。

**安装本插件**：克隆本仓库，在 ZCode 里 插件市场 → 添加 → 添加插件市场 → 选择本目录 → 个人 → Figma Bridge → 安装。
